# Record review guidance

Review a specific record revision. Record completeness dimensions, controlled confidence, reviewer identity from project configuration, and review time. Do not place review evidence, source/body text, private notes, or model traces in a public review-state object.

`unreviewed`, `in-review`, `human-reviewed`, and `corrected` are record metadata states. They are not release classes. A project policy can allow a public working release with unreviewed records when those states are accurately projected.

A substantive change creates a new record revision. A correction additionally records the prior and replacement revisions and, when applicable, the superseded release. Never edit an immutable historical projection in place.
