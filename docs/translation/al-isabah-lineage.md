# Al-Isabah lineage and deliberate adaptation

Issue: [#3](https://github.com/yaqub0r/book-repository-template/issues/3).
Source reference: `yaqub0r/al-isabah` at
`9dfb8cea613329917ea9c932baaaef0bb842e966` (October 14, 2026).

This port carries the current workflow's governing sequence and evidence model
into a book-neutral coordinator. It is an adaptation, not a verbatim copy of the
5,000-line biography-specific workflow and its historical schemas.

| Al-Isabah capability | Template adaptation |
| --- | --- |
| Pinned source hydration and integrity-bound local policies | Exact raw authority hash/length; profile-bound policies and methods |
| Issue-backed distributed claims | Stable unit IDs, overlap checks at claim/prepare/submit |
| Blind draft, independent critique, selective witnesses, adjudication | Ordered, write-once outputs with complete finding accounting |
| Captured exact execution and independent contexts | Selected Codex JSONL adapter with explicit coordinator/worker launch capture |
| Honorific and devotional preservation | Exact occurrence spans plus independent semantic audit |
| Durable bilingual names | Stable name IDs and source/final-English mention spans |
| Structural scope and reading surface | Generic heading/chain/report units; context-closed scopes; bilingual rendering |
| Agent completion separate from ongoing human review | All autonomous stages complete; humanReview remains unreviewed |
| Public-boundary proposal and immutable release | Private allowlisted submission; existing release controls remain unchanged |
| No English witness required | Disabled comparison with reason; optional independent post-critique comparison added |

Book-specific source parsers, title decisions, formula registries, facsimile
alignment, alternative-host exporters and content distribution schemas must be adopted and
qualified explicitly. They cannot safely be inferred from another book. The
template does not include actual book content, restricted evidence, model runs,
source permissions, licenses, releases or Al-Isabah's historical artifacts.

In particular, do not transfer a source permission to a commercial project just
because Al-Isabah used that source. The process is reusable; source and witness
rights remain artifact- and use-specific. Likewise, passing these synthetic tests
does not assert that Bukhari or another new book has been translated or qualified.
