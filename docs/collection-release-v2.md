## Canonical public registration

The direct v2 public adapter independently enforces exact IDs, ordinal/type/printed
labels and Arabic hashes for all12,059 occurrences; immutable first110 full-record
digests; and human-unreviewed state. A complete-shaped synthetic replacement or
unsupported human-review assertion cannot bypass the private collector.

The public compiler additionally accepts only the exact proposal digest registered
in `release/collection-projections.json`. That registry is intentionally empty
while the collection is unfinished. A hand-crafted proposal with genuine source
but replacement English/structure still fails registration. The private producer
uses a separate candidate validator after all actual core/companion/carry checks;
it emits only an ignored candidate and safe registration-candidate metadata for
independent review. This is not public archive admission. The generic public
compiler retains the strict registered adapter and cannot package the candidate
until the matching registry and public projection are promoted through the normal
reviewed change. Owner authorization already covers routine promotion and release;
this is a quality gate, not an additional operator permission request.

Supplemental hadith integrity checks reject report boundaries splitting printed
words/combining sequences, duplicate narrator occurrences and duplicate identical
physical-endpoint transmission edges. A single phrase governing distinct
coordinated recipients remains allowed. Private per-cue semantic inventories
support complete source reading, including explicit hearing/onward transmission
inside matn, and never substitute for fresh independent full Arabic/English audit.
The original frozen private-v1 contract and first release are not rewritten.

## Qualified narrator occurrence checks

The collector also requires `hadith_occurrence_checks.validate_bound` on each new
cohort. It verifies the reviewed occurrence inventory against the exact source
and ledger files before comparing literal narrator spans with source-specific
identity decisions. A known physical occurrence cannot remain unresolved or
acquire another identity. A transmission phrase wholly inside a protected
devotional formula is rejected. These checks do not guess identities from short
name strings, reject legitimate attached prepositions, or certify semantic
completeness. Fresh source-based structural review remains required.
